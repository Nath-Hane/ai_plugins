# Index des Documents Libres & Recherches (`.agents/docs/`)

Ce fichier est le sommaire obligatoire de tous les documents documentaires, synthèses ou recherches créés par les agents IA. 

> **Règle d'or pour l'Agent :**
> 1. Ne jamais parcourir récursivement les documents du dossier `docs/` sans avoir lu cet index au préalable.
> 2. Tout nouveau fichier créé dans `.agents/docs/` doit obligatoirement être consigné dans ce tableau avec un lien Markdown cliquable, une date, un résumé en 1 ligne et ses mots-clés.

---

## Registre des Documents

| :--- | :--- | :--- | :--- |
